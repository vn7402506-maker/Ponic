# Work Ponic — розовый дизайн-концепт

Это адаптивный статический макет главной страницы Work Ponic в розовой цветовой гамме.

## Состав
- `index.html` — структура страницы и тексты на русском языке.
- `styles.css` — оформление, розовая палитра и адаптивная вёрстка.
- `script.js` — мобильное меню.

## Как открыть
Распакуйте архив и откройте `index.html` в браузере. Для загрузки шрифта Manrope требуется интернет; при его отсутствии будет использован системный шрифт.

## Важно
Это демонстрационный фронтенд-концепт, а не готовая копия или обновление действующего сайта jb-hunter.app. Формы регистрации, личный кабинет, задания, финансовые операции и Telegram-интеграция не подключены к серверу. Кнопка перехода ведёт на исходный адрес `https://jb-hunter.app/`. Для публикации на домене и подключения реальных функций понадобятся исходный код сайта, серверная часть и доступы владельца.
